# GasDynamicsSciML / GasDynBench

[![validation](https://github.com/Ehsan-Roohi/GasDynamicsSciML/actions/workflows/ci.yml/badge.svg)](https://github.com/Ehsan-Roohi/GasDynamicsSciML/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Reproducible physics-guided neural benchmarks (GasDynBench) for five canonical compressible-flow relations:

1. Rayleigh forward and branch-wise inverse flow;
2. Fanno forward and branch-wise inverse flow;
3. direct and weak/strong inverse oblique shocks;
4. normal-shock localization inside a convergent-divergent nozzle; and
5. the implicit pressure step in an unsteady shock tube.

This repository is the auditable code and evidence package for manuscript **AITF-D-26-00044**, *Physics-Guided Neural Surrogates for Canonical Compressible Thermal-Fluid Relations*. It replaces the exploratory scripts previously stored at the repository root.

## What changed in the revision

- Rayleigh inversion now uses `T0/T0*`; the static `T/T*` maximum is at `M=1/sqrt(gamma)` and cannot be split consistently at the sonic state.
- Rayleigh and Fanno use independently trained subsonic/supersonic experts.
- Fanno reconstructs `4fL*/D = (M-1)^2 exp(g(M))`, which is non-negative and has the exact sonic limit.
- The oblique-shock inverse returns weak and strong branches separately. A released ablation shows that a naive MLP averages the incompatible roots.
- The direct oblique model uses a hard endpoint transform; the earlier extra samples were only soft anchors.
- The nozzle shock location is bounded analytically inside `[At, Ae]`.
- The shock-tube reference uses bracketed roots with residual checks and varies both `P4/P1` and `T4/T1`.
- Every new quantitative claim is stored in CSV. Corrected Rayleigh, Fanno, and oblique figures are generated by a dedicated script; accuracy summaries remain in tables.
- The MLP exposes an analytical input Jacobian. A safeguarded nozzle inverse-design audit verifies it against finite differences.
- A prescribed 100,000-state shock-tube workload measures an application-level many-query speedup against Brent.

## Reproduce the paper evidence

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
python -m unittest discover -s tests -v
gasdynbench --output results/revision
gasdynbench-highdim --output results/revision
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  PYTHONPATH=src python scripts/run_application_audits.py \
  --output results/revision \
  --latex-output manuscript/generated_timing_values.tex
PYTHONPATH=src python scripts/export_original_article_figures.py
```

The full CPU run trains the main models, three-seed ensembles, training-size studies, interpolation baselines, ablations, near-limit audits, and timing benchmarks. A reduced CI smoke run is:

```bash
gasdynbench --quick --output results/ci
gasdynbench-highdim --quick --output results/highdim-ci
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  PYTHONPATH=src python scripts/run_application_audits.py \
  --quick --output results/application-ci
```

## Key blind-test results

| Problem | Relative L2 | Relative Linf | MAE | Physical bound validity |
| --- | ---: | ---: | ---: | ---: |
| Rayleigh inverse | 1.642e-3 | 2.521e-3 | 2.227e-3 | 100% |
| Fanno inverse | 3.431e-3 | 3.761e-3 | 4.378e-3 | 100% |
| Oblique inverse | 7.990e-4 | 4.543e-3 | 5.076e-4 rad | 100% |
| Nozzle inverse | 1.936e-3 | 4.756e-3 | 3.522e-3 | 100% |
| Shock-tube implicit step | 9.490e-4 | 4.209e-3 | 2.388e-3 | 100% |

The neural models are not claimed to dominate every classical method. On covered one-dimensional tables, PCHIP is both faster and more accurate. In the unified single-thread timing run, neural inference for 5,000 queries is 18-810 times faster than repeated bracketed root finding, while interpolation is 5-10 times faster than the MLP. See [RESULTS.md](RESULTS.md) for the complete interpretation.

The generalized shock-tube audit extends the input from two to five physical parameters. At a matched approximately 4,096-state budget, interpolation relative L2 error grows from 0.0205% to 4.885%, while the bounded MLP gives 0.1771% in five dimensions. Interpolation is still slightly faster online; the demonstrated advantage is compact accuracy as regular-grid resolution becomes unaffordable.

The analytical-gradient nozzle audit solves nine target shock-location problems in at most six safeguarded Newton steps; the network Jacobian agrees with centered finite differences to within `1.37e-9` relative difference. For the prescribed 100,000-state shock-tube workload, the MLP is 16.5 times faster than one bracketed Brent solve per state with 0.0915% relative L2 error. The 5,000-query and 100,000-query shock-tube speedups (18.1 and 16.5) now come from one process, one model, and one Brent routine. These application checks do not change the paper's limited conclusion that interpolation remains preferable for covered one-dimensional tables.

`results/revision/range_generalization.csv` contains the reviewer-requested edge-holdout experiment: the models are trained on interior parameter boxes and tested on omitted low/high bands inside the declared physical domain.

`results/revision/nozzle_gradient_audit.csv`, `timing.csv`, and `shock_tube_many_query.csv` are generated consecutively by the unified application runner. `manuscript/generated_timing_values.tex` supplies both timing tables and their prose values from those CSVs, preventing the article and evidence from drifting apart.

## Scope and limitations

The five primary benchmarks assume a calorically perfect gas with constant `gamma=1.4`. The dimensional audit varies ideal-gas `gamma1`, `gamma4`, and `R4/R1`, but it does not validate reacting flow, variable heat capacity, multidimensional shocks, CFD coupling, or unrestricted extrapolation. Seed ensembles quantify optimizer variability, not calibrated probabilistic uncertainty. Input-domain checks reject unsupported states.
