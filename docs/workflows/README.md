# Problem-specific workflow diagrams

The five detailed Rayleigh, Fanno, oblique-shock, nozzle, and shock-tube
workflow diagrams are retained here as supplementary repository documentation.
They were moved out of the journal manuscript to reduce its length; the single
overall framework diagram remains in the article.

- `problem_workflows.tex`: editable TikZ source.
- `problem_workflows.pdf`: compiled five-page vector PDF.

The feature labels match the released implementation. In particular, the
Rayleigh and Fanno forward models use `[M, log(M), M^2]`, and the shock-tube
surrogate scales both logarithmic diaphragm-state inputs.
